# 🚀 GitHub Language Stats API

This project generates **dynamic GitHub language statistics** for any public GitHub user and displays them as **SVG charts**. It also provides a **public API** that anyone can use.

---

## 🔹 Features

- Generate dynamic **GitHub language stats**.
- Show **SVG charts** in README.md.
- Public **API endpoints** for language data.
- Deployable on **Vercel (FREE)**.
- Optional next-level features:
  - Language icons in SVG
  - GitHub token support (fix rate limits)
  - Dark/Light mode switch
  - Animated bars
  - Caching (1 hour)

---

## 📦 Deployment (FREE)

1. Go to [Vercel](https://vercel.com) and sign up / log in.
2. Connect your **GitHub account**.
3. Select the repo.
4. Click **Deploy**.

🔥 Done! Your API is live.
